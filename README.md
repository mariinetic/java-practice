# ☕ Exercícios em Java

Este repositório reúne diversos **exercícios resolvidos em Java**, desenvolvidos com o objetivo de praticar e fixar os conteúdos aprendidos nas disciplinas de **Lógica de Programação** e **Programação Orientada a Objetos (POO)**.

---

## 🎯 Objetivo

Consolidar os conhecimentos em:
- Sintaxe básica da linguagem Java
- Variáveis, operadores e controle de fluxo
- Arrays e estruturas de repetição
- Programação Orientada a Objetos (classes, métodos, atributos)
